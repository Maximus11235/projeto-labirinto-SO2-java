vamos trabalhar fazendo features a partir da DEVELOP 
como fazer isso?
git checkout develop
git checkout -b feature/nome-da-sua-feature
faça todos os codigos que precisa fazer e..
clique no controle de codigo fonte na barra lateral esquerda (se parece com um grafo)
adicione lá (utilizando o + que aparece quando se passa o mouse por cima do arquivo) SOMENTE o que deseja enviar ao github
no terminal, coloque:
git commit -m "mensagem do seu commit"
git push origin (nome da sua feature)
